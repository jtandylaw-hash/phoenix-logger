PHOENIX SIDELINE LOGGER — install
1. Upload this whole folder to a web host (GitHub Pages: repo -> Settings -> Pages -> deploy from main).
2. Open the URL in Safari on iPhone -> Share -> Add to Home Screen.
3. Launch from the icon. Works offline after first load. Data saves on the phone; Export CSV after each game.
Other teams: same URL; open Books (gear) -> set team name -> load playbooks (PDF/TXT) or Import config.
